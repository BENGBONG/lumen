# 2026-08-14

## git 分支集成（commit ab23aa9，67/67 测试全绿，已推 GitHub）

- **功能**：状态栏显示当前目录所属 git 仓库的分支徽标（分支名 + dirty 指示点），点击弹出本地分支列表，选择即 checkout 切换；切换后窗格自动 reload。每个窗格独立探测（StatusBarView 是 per-pane 的，天然双仓库支持）。
- **FileSystemKit/GitRepositoryService**：`/usr/bin/git` 子进程封装，不引入 libgit2。probe（向上找 .git + branch --show-current / rev-parse --short HEAD（detached）/ status --porcelain（dirty）/ branch --format）与 checkout；子进程走 Task.detached 不卡 MainActor。
- **PaneViewModel.gitInfo**：load() 与 reload() 后异步刷新（fire-and-forget Task），带「探测回来路径已变则丢弃」保护；归档虚拟目录内置 nil。
- **GitBranchSwitcher**（App/Services）：dirty 时 NSAlert 确认（默认按钮=取消，防回车误触）；checkout 失败把 git 原始 stderr 弹给用户。
- **测试**：7 个新单测用真实临时 git 仓库（init/commit/branch/checkout 全流程 + 冲突场景）。坑：非 git 目录的测试必须建在仓库外（仓库内子目录向上查找必命中 .git）；unborn 分支 `--show-current` 也能读出分支名（比预期好，直接显示分支名而非占位符）。
- **UI 细节**：Menu + `.menuStyle(.borderlessButton)` + `.menuIndicator(.hidden)` 让徽标看起来是纯文本；detached HEAD 图标换 circle 变体；空仓库显示「暂无本地分支」。
- **后续候选**：分支列表加 ahead/behind 计数、远程分支子菜单、新建/删除分支入口。
